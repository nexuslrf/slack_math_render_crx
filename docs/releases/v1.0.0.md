## Slack Math Viewer v1.0.0

The first release turns LaTeX in Slack Web messages into readable equations, including multiline matrices and Chinese annotations. All rendering runs locally using bundled KaTeX and fonts.

### Included

- Inline `$…$` and `\(…\)` equations; display `$$…$$` and `\[…\]` equations.
- Automatic updates for new messages, edits, and channel navigation.
- Support for math split across Slack formatting elements and display math across line breaks.
- A **Show original** button for each rendered message and an extension-wide on/off switch.
- Horizontally scrollable long equations. Inline code, code blocks, links, and message composers are excluded.
- No API key, external rendering service, or message-data collection.

### Install

1. Download **slack-math-viewer-v1.0.0.zip** from the release assets and extract it.
2. Open `chrome://extensions` in Chrome and enable **Developer mode**.
3. Click **Load unpacked** and select the extracted **slack-math-viewer** folder containing `manifest.json`.
4. Refresh Slack Web.

Keep the extracted folder in place. To update an existing installation, replace its contents, reload the extension in `chrome://extensions`, and refresh Slack.

Use the extension ZIP asset for installation; GitHub's automatically generated source archives contain the whole development repository. **SHA256SUMS.txt** provides the package checksum. This is an unpacked extension, not a signed CRX or Chrome Web Store release.

### Verification and limits

The release workflow runs five parser checks and seven Chromium integration checks before creating this draft. The tests cover all 82 equations in the supplied LiRoPE example, bundled font loading, original text preservation, message updates, and settings persistence.

Tests use local Slack-shaped pages; compatibility with a live signed-in workspace has not been verified. Invalid or unsupported TeX remains visible as source text. Missing underscores and other errors in the original notation are not corrected automatically. Slack UI changes may require selector updates. This release supports Slack Web, not the native Slack desktop app.
